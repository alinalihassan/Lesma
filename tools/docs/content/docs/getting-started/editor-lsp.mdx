## VS Code extension

The repository ships a VS Code extension under `tools/vscode`. It launches the native **`lesma-lsp`** executable and talks LSP over stdio.

Build or install `lesma-lsp` first (CMake option `LESMA_BUILD_LSP`), ensure it is on your `PATH`, then load the extension in VS Code.

## UTF-8 positions

`lesma-lsp` advertises **UTF-8** position encoding to clients. Your editor must send `Position.character` as **UTF-8 code units (bytes)** from the start of the line. If the client assumes UTF-16 code units, diagnostics and cursors can drift on non-ASCII source.

## Workspace discovery

With the **lsp** vcpkg feature enabled, the language server can discover `.les` files across a Git work tree using **libgit2** (no shelling out to `git`). Configure CMake/vcpkg per **AGENTS.md** if you need that mode.
