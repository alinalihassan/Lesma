## VS Code extension

The repository includes a VS Code extension under `tools/vscode`. It starts the native **`lesma-lsp`**
executable and talks to it over the standard Language Server Protocol (stdio).

1. Build or install **`lesma-lsp`** (CMake option `LESMA_BUILD_LSP`) and ensure the binary is on
   your `PATH`.
2. Open the `tools/vscode` folder in VS Code (or install the packaged extension, if you have one)
   and open a `.les` workspace.

You should see diagnostics, completion, and navigation features as you edit.
