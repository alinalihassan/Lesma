You can use Lesma in two ways: install a **prebuilt release** (fastest), or **build from source** (for contributors and bleeding-edge features).

## Quick install (release)

Run the installer script from the Lesma repository. It downloads the latest release for your platform and lays out the `lesma` binary and standard library:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/alinalihassan/Lesma/main/scripts/get-lesma.sh)"
```

Verify the install:

```bash
lesma --version
```

## Build From Source

If you develop the compiler or need a custom build, see [Build From Source](/docs/getting-started/build-from-source) for CMake presets, vcpkg, and LLVM setup.
