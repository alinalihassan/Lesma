## Hello world

Create `hello.les`:

```
print("Hello World")
```

Run it:

```bash
lesma run hello.les
```

`print` comes from the standard environment available to small programs (same idea as other examples in the test suite).

## Compile to an object file

To emit LLVM-backed object code instead of using the JIT:

```bash
lesma compile hello.les -o hello.o
```

Exact linking steps depend on your platform; the compiler focuses on generating objects and driving LLVM.

## Slightly larger shape

Lesma supports **functions**, **classes**, **modules**, and more. A tiny class-based sketch (see also `tests/lesma/success/class.les` in the repository):

```
export class Greeter
    def new()
        pass

    def hi() -> void
        print("Hello")

var g = Greeter()
g.hi()
```
