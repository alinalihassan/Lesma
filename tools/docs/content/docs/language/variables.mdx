Lesma supports imperative programming: you can introduce **mutable** storage and update it with assignment.

## `var` and `let`

Use **`let`** when the binding should not be reassigned, and **`var`** when you plan to assign to it again:

```les
let message: str = "hi"
var total: int = 0
total = total + 1
```

## Assignment

Ordinary `=` updates a `var`. Compound assignment operators work too:

```les
var y: int = 100
y += 1
```
