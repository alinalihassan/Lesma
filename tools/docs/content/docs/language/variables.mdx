Lesma supports imperative programming: you can introduce **mutable** storage and update it with assignment.

## `var` and `let`

The language distinguishes binding forms (see compiler tests such as `var_decl.les` and `assignment.les` in the repository). Use the form appropriate to whether you need reassignment.

## Assignment

Assignment expressions update existing bindings. Compound assignment operators are supported (`assignop.les`).
