Lesma supports **traits** (interfaces with optional default methods) and **generics** over functions and classes.

## Where to learn from code

The fastest way to stay accurate is to read the compiler tests:

- Traits: `trait_default_method.les`, `trait_bounds_mod.les`, `trait_import_star.les`, …
- Generics: `generics.les`, `generics_class.les`, `generic_class_constructor.les`, …
- Intersection and advanced bounds: `trait_intersection_bounds.les`, `trait_intersection_import.les`

This page intentionally stays short: the language is evolving and the **test suite** is the specification surface.
