Lesma supports **traits** (interfaces with optional default method bodies) and **generics** on functions and classes.

## Traits

A trait declares required methods. A class **implements** a trait with `impl`:

```
export trait Describable
    def label() -> str

export class Box impl Describable
    def new()
        pass

    def label() -> str
        return "box"

var b = Box()
print(b.label())
```

Default bodies on trait methods are allowed—classes that `impl` the trait inherit them unless they override.

## Generic functions

Type parameters appear in angle brackets before the parameter list:

```
def identity<T>(x: T) -> T
    return x

def max_val<T>(a: T, b: T) -> T
    if a > b
        return a
    return b
```

## Bounds

Require that a type parameter implements a trait:

```
def print_label<T: Describable>(x: T) -> void
    print(x.label())
```

## Generic classes

Classes can carry type parameters and participate in inheritance; combine generics with `:` / `impl` as needed for your program.
