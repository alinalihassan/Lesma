Lesma programs are built from **expressions** that evaluate to typed values. Literals are the simplest expressions.

## Numbers

Integer and floating-point literals behave as you would expect; types are inferred in context or annotated explicitly (see [Types](/docs/language/types)).

Integer literals may use an explicit radix prefix:

- **Binary:** `0b` or `0B` followed by binary digits (`0`–`1`), e.g. `0b1010`
- **Octal:** `0o` or `0O` followed by octal digits (`0`–`7`), e.g. `0o755`
- **Hexadecimal:** `0x` or `0X` followed by hex digits (`0`–`9`, `a`–`f`, `A`–`F`), e.g. `0xFF`

Decimal literals are unchanged. Only a single leading `0` is allowed before the radix letter; for example use `0b1`, not `00b1`.

```les
let n = 0b01010101 + 0x10 + 0o17
```

## Strings

String literals use double quotes. You can splice values into a string with **`${…}`**:

```les
let name: str = "Lesma"
print("Hello, ${name}!")
let n: int = 7
print("n=${n}")
```

For calling C libraries and using nul-terminated string parameters, see [Foreign Function Interface](/docs/language/ffi).

## Booleans

Boolean literals `true` and `false` participate in logical operators (see [Control Flow](/docs/language/control-flow)).

## Operators

Arithmetic (`+`, `-`, `*`, `/`, `%`), comparison (`==`, `!=`, `<`, `>`), and logical combinations (`and`, `or`, `not`) combine expressions as you would expect.

## List and dict literals

You can construct **`list<T>`** and **`dict<K, V>`** values with bracket literals; the compiler infers element types when possible.

```les
let nums = [1, 2, 3]
let table: dict<str, int> = {"a": 1, "b": 2}
```

See the [standard library overview](/docs/language/stdlib-overview) for types like `list` and `dict` and how they are used in practice.
