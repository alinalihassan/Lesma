The **standard library** ships with the toolchain as Lesma modules. You load them with the same `import` / `from` syntax you use for your own files.

## Core modules

- **`base`** — built-in types and helpers (`list`, `dict`, `str`, `range`, `Result`, `Display`, `print`, `file`, `random`, …).
- **`json`** — JSON parsing/stringifying plus `Serializable`.
- **`math`** — numeric helpers (`abs`, `sin`, `ceil`, …).
- **`time`** — `sleep` (seconds as `int` or `float`).

## Typical imports

```les
from json import Json
from time import sleep
from math import ceil

print("${ceil(3.2)}")
match Json.stringify({"ok": true}) {
    Result.Ok(text) => print(text)
    Result.Err(err) => print(err)
}
sleep(0.01)
```

## Prelude highlights from `base`

Except when compiling `base.les` itself, Lesma implicitly loads that module. Common exported names
available in everyday code include:

- `print`, `input`, `exit`
- `str`, `list<T>`, `dict<K, V>`, `range`
- `Iterator<T>`, `Iterable<T>`
- `Display`
- `Result<T, E>`

## JSON

The `json` module provides:

- `Json.parse(...)` for objects and arrays
- `Json.stringify(...)` for JSON-compatible values
- `Serializable<T>` for typed encode/decode helpers
- `JsonErr` for parse and conversion failures

Typical imports:

```les
from json import Json, JsonErr, Serializable, JsonValue
```
