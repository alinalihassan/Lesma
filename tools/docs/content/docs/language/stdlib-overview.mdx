The **standard library** ships with the toolchain as Lesma modules. You load them with the same `import` / `from` syntax you use for your own files.

## Core modules

- **`base`** — built-in types and helpers (`list`, `dict`, `str`, `range`, `print`, `file`, `random`, …).
- **`math`** — numeric helpers (`abs`, `sin`, `ceil`, …).
- **`time`** — `sleep` (seconds as `int` or `float`).

## Typical imports

```
from time import sleep
from math import ceil

print("${ceil(3.2)}")
sleep(0.01)
```
