Functions bundle behavior with a typed interface.

## Definition

Define a function with `def`, parameters, an optional return type, and a body:

```
def add(a: int, b: int) -> int
    return a + b
```

## Calls

Call syntax uses parentheses and comma-separated arguments. Nested and higher-order patterns appear in tests such as `function_call.les` and `nested_function_calls.les`.

## Recursion

Recursive functions are supported (`function_recursive.les`).

## Default arguments

Default parameter values are supported (`function_default_value.les`).
