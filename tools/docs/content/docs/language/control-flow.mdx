## Conditionals

`if` / `else` chains choose between branches (`ifelse.les`, `if_return.les`).

## Loops

`while` loops and `for`/`in` iteration over iterables are both used in the language (`while.les`, `for_in_break_continue.les`, list and range examples).

## Break and continue

Loop control transfer uses `break` and `continue` (`break.les`, `continue.les`).

## Exit

Programs can terminate with `exit(code)` where appropriate for tests and scripts.
