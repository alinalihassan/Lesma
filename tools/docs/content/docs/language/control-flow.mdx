## Conditionals

`if` / `else` chains pick a branch. You can return early from a function:

```
def sign(n: int) -> str
    if n < 0
        return "neg"
    else if n > 0
        return "pos"
    return "zero"
```

## Loops

`while` runs while a condition holds. `for` / `in` iterates any **iterable** (for example `range` or a `list`):

```
var i: int = 0
while i < 3
    print(i)
    i = i + 1

for j in range(1, 4)
    print("${j}")
```

## Break and continue

`break` leaves the innermost loop; `continue` skips to the next iteration:

```
for k in range(1, 10)
    if k == 3
        continue
    if k == 7
        break
    print("${k}")
```

## Exit

Terminate the process with **`exit(code)`** when a script should signal failure to the shell:

```
if bad_condition
    exit(1)
```
