Use comments to explain **why** non-obvious code exists; let types and names carry the **what**.

## Line comments

`#` starts a line comment through the end of the line.

```les
# Compute the next value
let n = x + 1
```

For a short “block” of commentary, use several `#` lines in a row—the lexer only knows line comments, but this is the usual style in Lesma sources.

## Documentation in the LSP

When one or more `#` lines sit **immediately above** a declaration, with only blank lines between the comment block and the declaration, the Lesma language server treats that text as **Markdown documentation** for the symbol. It is shown in **hover** (and in completion detail where applicable), so editors can surface the same prose you keep in source.

This applies to major declarations such as **functions**, **methods**, **classes**, **enums**, and **traits**—the same pattern you would use to document an API in-tree.

## Line continuation

A `\` at the end of a physical line continues the statement on the next line:

```les
let x = \
    100 + \
    1
```
