Use comments to explain **why** non-obvious code exists; let types and names carry the **what**.

## Line comments

`#` starts a line comment through the end of the line.

## Block comments

Block comment syntax follows the style used in Lesma sources (see examples under `tests/lesma/success/` and `src/stdlib/`).

## Line continuation

Long physical lines can be split with line continuation where the grammar allows (`line_continuation.les`).
