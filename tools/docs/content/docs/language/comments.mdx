Use comments to explain **why** non-obvious code exists; let types and names carry the **what**.

## Line comments

`#` starts a line comment through the end of the line.

```
# Compute the next value
let n = x + 1
```

For a short “block” of commentary, use several `#` lines in a row—the lexer only knows line comments, but this is the usual style in Lesma sources.

## Line continuation

A `\` at the end of a physical line continues the statement on the next line:

```
let x = \
    100 + \
    1
```
