Lesma programs split across **modules** (typically one `.les` file per unit of compilation, plus imports).

## Import a file

```
import "other.les"
```

Resolution rules depend on paths relative to the project and stdlib layout (see compiler behavior and tests such as `import.les`).

## Import symbols

Selective imports:

```
from time import sleep as sleep_test
from "class.les" import Animal
```

Star imports exist (`import_asterisk.les`).

## Export

Mark declarations **`export`** when other modules should see them (`export class`, `export def`, …).
