Lesma is a **compiled**, **statically typed**, **imperative**, **object-oriented** language that targets **LLVM**. The compiler is written in C++23; the standard library is written in Lesma (`.les` files shipped with the toolchain).

Use this site in three ways:

- **Start at the hub** — [Back to home](/) lists the main tracks with links into each section.
- **Follow getting started** — [Installing Lesma](/docs/getting-started/install), then [your first program](/docs/getting-started/first-program).
- **Try code in the browser** — [Playground](/playground) (embedded UI; same origin in production — see [Playground](/docs/getting-started/playground)).

The compiler exposes a small CLI (`lesma run`, `lesma compile`) and an optional language server (`lesma-lsp`) for editor integration.
