Lesma is a **compiled**, **statically typed**, **imperative**, **object-oriented** language you can
install locally or try in the browser. Programs start from **top-level statements** in the file you
run—there is no required `main` function.

Use this site in three ways:

- **Start at the hub** — [Back to home](/) lists the main tracks with links into each section.
- **Follow Getting Started** — [Installing Lesma](/docs/getting-started/install), then
  [A Tour of Lesma](/docs/getting-started/tour) or [Hello World](/docs/getting-started/first-program).
- **Try code in the browser** — [Playground](/playground) (embedded UI; same origin in production —
  see [Playground](/docs/getting-started/playground)).

The compiler ships with a small CLI (`lesma run`, `lesma compile`) and an optional language server
(`lesma-lsp`) for editor support.
