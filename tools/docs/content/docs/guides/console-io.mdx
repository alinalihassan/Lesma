## Printing values

The standard library provides overloaded **`print`** for common types (`str`, `int`, `float`,
`bool`, and others). Each call adds a trailing newline, similar to many scripting languages.

```
let n: int = 42
print("n is ${n}")
print(n)
```

Use **`${expression}`** inside string literals for interpolation.

## Reading a line from the terminal

**`input()`** reads a line from standard input. An optional prompt string is printed first (without
a newline), matching the usual “prompt then read” pattern.

```
let name: str = input("Your name: ")
print("Hello, ${name}!")
```

## Formatted output

**`print`** is the usual choice. When you need C-style format strings (fixed width, hex, and so on),
declare the C function and call it through the [Foreign Function Interface](/docs/language/ffi)—for
example `printf` with a format string and matching arguments.
