This tutorial is a **conceptual** walkthrough. Lesma’s exact standard I/O surface evolves; pair these ideas with working patterns from `tests/lesma/success/` (for example file and text tests such as `file_text.les`) and adjust to the APIs available in your toolchain version.

## Problem

The computer picks a secret number; the player guesses until they get it right. The program reports “too high” or “too low”.

## Structure

1. Choose a secret value (for learning, start with a **constant**).
2. Loop until the guess matches.
3. Inside the loop, read a guess and branch with `if` / `else` ([Control flow](/docs/language/control-flow)).

## Stretch goals

- Count guesses.
- Bound the loop with a maximum number of attempts.
- Swap the constant for a pseudo-random value once you locate the right stdlib or external hook for your build.
