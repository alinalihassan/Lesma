The **`math`** module ships with the toolchain. Import the
symbols you need so the compiler only pulls in what you use.

## Absolute value and rounding

```les
from math import abs, ceil, floor, round

print("${abs(-5)}")
let x: float = 3.7
print("${ceil(x)} ${floor(x)} ${round(x)}")
```

## Trigonometry and friends

The module forwards common `<math.h>` functions, **`sin`**, **`cos`**, **`tan`**, **`asin`**, and
others, so you can call them directly after importing.

```les
from math import sin, cos

let r: float = sin(0.0)
print("${r}")
```
