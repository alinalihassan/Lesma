---
title: Comments
description: Document Lesma code with line comments.
---

Comments begin with `#` and continue to the end of the line.

```txt
# My first comment
```

For multiple lines, repeat `#` on each line:

```txt
# This
# is
# a
# multiline
# comment
```

Comments usually appear above the code they describe, but inline comments are
also valid.

```txt
# approximate pi value
let pi = 3.14

let delta = 0.001  # difference threshold
```
