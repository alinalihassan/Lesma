---
title: Hello World
description: Write and run your first Lesma program.
---

Now that Lesma is installed, create a source file named `main.les`.

```txt
print("Hello World!")
```

## Run the program

```bash
lesma run main.les
```

If everything is set up correctly, the program prints:

```txt
Hello World!
```
